# F03 — Captura de áudio contínua + sessão de ditado

**Status:** [x] concluído (F03.1–F03.6, sessão validada no S26 Ultra)

Captura contínua em 16 kHz mono, janelas com overlap, VAD com hangover,
detecção de fim de fala, cancelamento e indicador de status. Sem rede no
caminho crítico. Base para F04 (transcrição incremental) e F06 (prévia).

Inspiração Handy (MIT, `cjpais/handy`, somente referência — nada copiado):
`SileroVad 30 ms`, `VAD_PREFILL 450 ms`, `OFFLINE_HANGOVER 450 ms`,
`STREAMING_HANGOVER 1650 ms`, `ONSET 60 ms`, `SmoothedVad`, `tail_report`,
`StreamRouter Feed/Finalize/Cancel FIFO`, `committed + tentative`,
`extra_recording_buffer_ms`, `vad_enabled` toggle.

## Observações técnicas (arquitetura Kotlin)

- `commonMain` nunca importa Android; `androidMain` fornece `AudioRecordCapture`
  e `SileroVad` (stub energia primeiro, ONNX depois). DI via Koin `sharedModule`
  + `androidModule` (a criar).
  - Dependências fixadas em `libs.versions.toml`: `kotlinx-coroutines-core/test`
    `1.10.1` (F03.4 implementado; registrado abaixo).
- Concorrência: um worker por stream (`workerId` monotônico + `compareAndSet`,
  como Handy); engine/transcrição F04 é arrendada ao worker e devolvida via
  `returnEngine` (descarta se modelo trocou). `LoadingGuard`/`Condvar`
  equivalente com `Mutex + CompletableDeferred`.
- Segurança: nenhum áudio sai do aparelho nesta fase; nenhum segredo envolvido.
