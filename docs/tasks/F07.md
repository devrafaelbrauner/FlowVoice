# F07 — Dicionário pessoal + aprovações

**Status:** [x] concluído

O usuário aprova grafias/termos (nomes, jargão clínico) que passam a ser
aplicados na revisão da prévia. Persistência **local**; sync é F11.

## Escopo

- `DictionaryTerm` + store no `shared` (sem Android na interface).
- Sugestões a partir do texto transcrito.
- Aprovar / rejeitar; aplicar grafia aprovada na prévia (case-insensitive).
- Persistência local no Android (não é segredo; não usar o cofre da chave).

## Fora do escopo

- Sync (F11), notas (F08), pontuação por IA (F09), FAB (F12).

## Sub-tarefas

- [x] **F07.1 — Contratos e aplicação**
  - Store: listar aprovados, aprovar, rejeitar, pendentes.
  - `DictionaryApplier` substitui ocorrências pela grafia aprovada.
  - `TermSuggester` extrai candidatos do texto (tokens, sem stopwords curtas).
  - **Aceite:** testes desktop de apply, suggest, approve/reject.

- [x] **F07.2 — Persistência Android**
  - SharedPreferences do app (não cifrado). Abstraction no `shared`.
  - **Aceite:** `:androidApp:assembleDebug` verde.

- [x] **F07.3 — UI de diagnóstico**
  - Lista de sugestões (aprovar), lista de aprovados, campo para termo novo.
  - Prévia/inserção usam o texto já revisado pelo dicionário.
  - **Aceite:** testes + assembleDebug.

## Critério de aceite da fase

- Termos aprovados persistem e alteram a prévia; nenhum segredo nos logs.
