# F06 — Texto ao vivo (prévia)

**Status:** [x] concluído

Prévia ao vivo da transcrição incremental: o texto cresce por **revisão**
(overlap de janelas, sem concatenação cega), com distintivo visual
**provisório vs finalizado**. No finalize da POC, inserir o texto final no
campo ativo via a rota F02.

## Escopo

- `LivePreviewAssembler` no `shared` (testável no desktop).
- UI: trecho finalizado vs provisório (em transcrição / sessão ativa).
- Inserção única no `Finalizar` (`commitText`, fallback `ACTION_SET_TEXT`).
- Cancelar não insere.

## Fora do escopo desta fase

- Dicionário pessoal (F07).
- Notas (F08).
- Revisão/pontuação por IA (F09).
- Botão flutuante / UX de produção (F12).

## Sub-tarefas

- [x] **F06.1 — Assembler de prévia**
  - Merge de trechos `Ok` por overlap de tokens (sufixo/prefixo).
  - Trechos `Failed` ignorados; `Transcribing` vira provisório (`…`).
  - Sessão ativa → texto montado é provisório; sessão finalizada → finalizado.
  - **Aceite:** testes desktop cobrem overlap, falha no meio, vazio e sessão ativa.

- [x] **F06.2 — UI distintivo**
  - Prévia na tela de diagnóstico com dois estilos.
  - **Aceite:** `:androidApp:assembleDebug` verde.

- [x] **F06.3 — Inserção no finalize**
  - Esperar a fila F04; inserir só o texto finalizado.
  - Logs: rota e tamanho; nunca chave nem áudio.
  - **Aceite:** cancelar não insere; finalize chama F02 uma vez.

- [x] **F06.4 — Verificação**
  - `./gradlew :androidApp:assembleDebug` e `:shared:desktopTest`.

## Critério de aceite da fase

- Testes verdes; prévia com distintivo provisório/final; inserção no finalize;
  nenhum segredo nos logs.
