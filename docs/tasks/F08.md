# F08 — Notas

**Status:** [x] concluído

Criar, listar e editar notas com persistência **local**. Sync é F11.

## Escopo

- `Note` + store no `shared`.
- CRUD mínimo: criar (a partir da prévia), listar, editar corpo/título, apagar.
- Persistência local Android (JSON em SharedPreferences).

## Fora do escopo

- Sync (F11), pontuação IA (F09), FAB (F12).

## Sub-tarefas

- [x] **F08.1 — Contratos e store**
  - `Note` (id, título, corpo, updatedAt).
  - Store: list, get, upsert, delete.
  - **Aceite:** testes desktop de criar/editar/apagar e ordem por data.

- [x] **F08.2 — Persistência Android + UI**
  - Salvar localmente; lista na tela de diagnóstico; “salvar prévia como nota”.
  - **Aceite:** `:androidApp:assembleDebug` e `:shared:desktopTest` verdes.

## Critério de aceite da fase

- Notas persistem entre reinícios; nenhum segredo nos logs.
