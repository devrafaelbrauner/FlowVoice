# F13 — Preparação para Windows

**Status:** [~] em andamento

Levar o núcleo do FlowVoice (captura, transcrição incremental, prévia e
inserção direta) para o desktop, com foco em **Windows**: Compose Desktop +
JNA (`SendInput`) para inserir no app ativo e DPAPI para guardar a chave
OpenRouter. O `shared` já compila para `jvm("desktop")`; esta fase preenche
as implementações de plataforma e cria o app desktop mínimo.

## Escopo

- Contrato de inserção de texto no app ativo (`TextInserter`) no `shared`.
- Seleção de implementação por sistema operacional (Windows / macOS / Linux).
- Captura de áudio desktop via `javax.sound.sampled` (16 kHz, PCM 16-bit mono,
  mesma política do F03).
- Inserção no Windows via JNA `SendInput` com `KEYEVENTF_UNICODE`;
  implementação diagnóstica (não insere) nos demais sistemas.
- Chave OpenRouter no Windows cifrada com DPAPI (`Crypt32Util`); nos demais
  sistemas, falha explícita — nunca em claro.
- Módulo `desktopApp` (Compose Desktop) com chave, iniciar/finalizar ditado,
  prévia e inserir.

## Fora do escopo desta fase

- Atalho global e janela flutuante que não rouba o foco (UX de produção).
- Dicionário pessoal, revisão, notas e sync no desktop (F07–F11 no Android).
- Cofre de chaves do macOS (Keychain) e do Linux (Secret Service).
- Instalador assinado (MSI/EXE com certificado) — F14.

## Sub-tarefas

- [ ] **F13.1 — Contratos e seleção por sistema**
  - `TextInserter` + `TextInsertionResult` no `commonMain` (sem Android).
  - `DesktopOs` detecta Windows / macOS / Linux a partir de `os.name`.
  - **Aceite:** `:shared:desktopTest` cobre a detecção de sistema.

- [ ] **F13.2 — Captura de áudio desktop**
  - `JavaSoundAudioCaptureEngine` implementa `AudioCaptureEngine` com
    `TargetDataLine` (PCM assinado, little-endian, 16 kHz, mono).
  - Falhas de linha/permissão viram `AudioCaptureException`.
  - **Aceite:** testes desktop cobrem o formato e o erro de linha indisponível;
    captura real validada em Windows (F13.7).

- [ ] **F13.3 — Inserção via `SendInput`**
  - Plano de teclas puro: uma unidade UTF-16 por evento (pares substitutos
    enviados como duas unidades), `\r\n`/`\r`/`\n` → `VK_RETURN`.
  - Mapeamento para `KEYBDINPUT` (`wScan`, `KEYEVENTF_UNICODE`,
    `KEYEVENTF_KEYUP`) e envio numa única chamada `SendInput`.
  - Outros sistemas: `UnsupportedTextInserter` (não insere, explica o motivo).
  - Logs e mensagens com tamanho do texto, nunca o conteúdo.
  - **Aceite:** testes desktop cobrem ASCII, acentos, emoji e quebras de linha;
    inserção real validada em Windows (F13.7).

- [ ] **F13.4 — Chave OpenRouter cifrada (DPAPI)**
  - Arquivo em `%LOCALAPPDATA%\FlowVoice` (não roaming) com o blob DPAPI.
  - Escrita atômica; leitura que não decifra é tratada como ausente.
  - Sem cofre (macOS/Linux): `UnavailableSecretStore` falha ao salvar.
  - **Aceite:** testes desktop com cifra falsa provam que o arquivo não contém
    a chave em claro; round-trip DPAPI real validado em Windows (F13.7).

- [ ] **F13.5 — DI desktop**
  - `desktopModule(os)` liga captura, sessão, cofre e inserção por sistema.
  - **Aceite:** testes desktop cobrem a escolha de implementação por sistema.

- [ ] **F13.6 — App Compose Desktop**
  - Módulo `desktopApp` (plugin `org.jetbrains.compose`), janela mínima:
    chave OpenRouter, iniciar/finalizar/cancelar ditado, prévia provisório vs
    finalizado e "inserir no app ativo" (minimiza a janela e insere após
    contagem).
  - Versão do Compose Multiplatform fixada em `libs.versions.toml` e
    compatível com Kotlin 2.1.10.
  - **Aceite:** `:desktopApp` compila; `./gradlew :desktopApp:run` abre a
    janela (macOS de desenvolvimento).

- [ ] **F13.7 — Validação em Windows real**
  - `./gradlew :desktopApp:run` e `:desktopApp:packageMsi` em Windows 10/11.
  - Salvar chave (DPAPI), ditar pt-BR, inserir no Bloco de Notas, navegador e
    Word; conferir emoji, acentos e quebra de linha.
  - Conferir app-alvo elevado (UIPI bloqueia `SendInput`) e mensagem de falha.
  - **Aceite:** evidência (versão do Windows, apps testados, prints/logs sem
    chave) registrada neste arquivo.

## Critério de aceite da fase

- `:shared:desktopTest`, `:androidApp:assembleDebug` e o build do
  `desktopApp` verdes.
- Inserção direta e chave cifrada funcionando em Windows real (F13.7).
- Dependências novas registradas em `THIRD_PARTY_NOTICES.md`.
